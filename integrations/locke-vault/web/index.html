iCloud Photos experimental

Lets the vault read the photos of one album in your iCloud library (for example an album named "Locke"), so you can stage them here. It uses Apple's private web access: you sign in with your Apple ID once, your password is never stored, and the Apple session is kept encrypted. It may stop working when Apple changes things, and it can't work if Advanced Data Protection is on for your account. Only users approved by an administrator can use it.
